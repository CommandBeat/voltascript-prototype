# A guide to making Voltascript libraries
This is how to make a library in Voltascript

## Steps
1. Make a folder named after your library
2. Create a main voltascript(.vs) file with a class(the name being the same as your library name)
3. Add it to the "libraries" folder in "voltascript"

Now Voltascript can recognize your library

## Addons
You can add extra files to your library for extra functionality
